Using an archive

In a MapLibre style, the source URL is the archive URL with a pmtiles:// prefix:

pmtiles://{{$.Origin}}/{{(index .Archives 0).Name}}

Extracting a region

The pmtiles CLI reads a remote archive over Range and transfers only the bytes it needs, so a regional subset costs no server-side work:

pmtiles extract {{$.Origin}}/{{(index .Archives 0).Name}} region.pmtiles \
  --bbox=144.5,-38.5,145.6,-37.4
